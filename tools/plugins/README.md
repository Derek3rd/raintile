# Plugins shipped in the package

`32bit/HotKey.dll` and `64bit/HotKey.dll`: the **HotKey** plugin for Rainmeter, version 1.0.0.12, by Brian Ferguson — source and license: <https://github.com/brianferguson/HotKey.dll>.

`tools/build_rmskin.py` puts them in the `.rmskin` (`Plugins\32bit` and `Plugins\64bit`), so installing Raintile installs the plugin too.
