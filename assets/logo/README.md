# Raintile logo

The sources of the logo, as SVG (the name is drawn as outlines: no font needed).

| File | What it is |
| --- | --- |
| `raintile-logo.svg` | the symbol over the name, on a transparent background |
| `raintile-symbol.svg` | the symbol alone, square: icons (the Options program, the package, favicons) |
| `raintile-social.svg` | the logo on its dark background, 1280 x 640: GitHub's social preview |

The symbol: a 3 x 3 grid of tiles (borders from `#5fe3f5` to `#2f7fe0`, inside
`#173a52` to `#11273a`) and three drops, `#3ab8f0`, whose tip rises above their
tile and whose round bottom cuts its lower border; around each drop the tile
(border and inside) is cut away, so the background shows there. The name is
Inter: RAIN ExtraBold, TILE Medium, LAUNCHER Medium, spaced.

PNGs and the `.ico` are made from these files at the size needed (any SVG
renderer: a browser, Inkscape, `rsvg-convert`); they are not kept here.
